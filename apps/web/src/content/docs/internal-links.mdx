Use it when a page deserves more links from the rest of your site. Pick the target page and the command looks for pages that cover the same topic but do not link to it yet.

## Run it

Install the CLI and run setup if you have not yet, then ask your agent or run it with the page that should get the links:

```sh
seo internal-links --url https://example.com/pricing
```

It finds the Search Console property from the URL. Add `--site` only when you have more than one property that covers it.

It looks at the last 90 days of Search Console data. For other dates, add `--start-date` and `--end-date`. Everything else is set for you and shown in the result: it checks up to 40 pages live, returns up to 20, and leaves out searches for your brand name.

## What comes back

- Pages whose Search Console queries overlap with the target page's topic.
- A live check of those pages, keeping only the ones that do not already link to the target.
- The queries behind each suggestion, so you can see why it was picked.
- Where the link fits: the sentence on the source page that names the target best, and anchor text taken from that sentence. When no sentence names the target, it says so, because a link there needs new text.

Pages with a sentence that fits come first. The order is a rough guide, not a forecast. Read the source page, add a link only where it helps a reader, and run a [crawl](/docs/crawl) afterwards to confirm it is there.
