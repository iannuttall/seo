Each command has the same name in the CLI and a matching tool in the hosted MCP. The results are the same either way.

<CommandCards />

## Which tool each command uses

| CLI | Hosted MCP tool | Needs |
| --- | --- | --- |
| `seo report` | `seo_report` | Search Console |
| `seo page` | `seo_page` | Search Console and a URL |
| `seo compare` | `seo_compare` | Search Console and a date |
| `seo index` | `seo_index` | Search Console |
| `seo research` | `seo_research` | A DataForSEO, Ahrefs or Semrush key |
| `seo data` | `seo_data` | Search Console or an analytics account |
| `seo crawl` | CLI only | A site URL |
| `seo internal-links` | CLI only | A site URL and a target page |

`seo start` sets up the CLI. It is covered in the [CLI guide](/docs/cli).

## Start with the report

Run the [SEO report](/docs/commands/report) without a section first. The overview shows where clicks and impressions moved, and each section count tells you where to look next. Running five narrow commands before that usually means reading more rows than you need.
