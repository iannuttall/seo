## What you need

- A Google account that can see at least one Search Console property.
- An AI agent that supports MCP, such as Claude Code, Codex or Cursor.
- Node.js (the current LTS release) on the machine your agent runs on, for the CLI.

Google Analytics, other analytics tools and keyword data are optional. You can add them later.

## Set up SEO Skill

Pick your agent, copy the prompt and paste it into the agent. It installs the CLI, adds the hosted MCP server and the skill, and stops when it needs you to sign in with Google. You don't type any commands.

<SetupPrompts id="getting-started-setup" />

The hosted MCP runs on seoskill.dev and reads your data each time your agent asks. The CLI runs on your machine for the jobs the hosted server can't do, such as a site crawl and Bing. The [hosted MCP guide](/docs/mcp) covers other clients, the tools and how sign-in works. For cloud agents and CI machines that start fresh each time, follow the [cloud agents guide](/docs/cloud-agents) instead.

## Run it yourself

To set it up by hand, the [CLI guide](/docs/cli) covers `seo start` and each choice it asks about, and the [hosted MCP guide](/docs/mcp) has the command for each agent.

## Ask for your first report

Ask your agent in plain words:

```prompt
Run the SEO report for example.com
```

The agent calls the report without a section first. You get an overview of clicks, impressions, click-through rate and position against the previous period, plus a count and the top rows for each section. Then ask for the section that looks interesting:

```prompt
Show me the quick wins for example.com
```

## Facts, not advice

Every result says what the data shows, such as a page at position 6 with a click-through rate below your site's own curve. It does not tell you what to change. Your agent shows you the facts and you decide what to do with them.

Start with the [SEO report](/docs/report), then use the [other commands](/docs#docs-commands) when you have a narrower question.
