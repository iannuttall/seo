[TypingMind](https://www.typingmind.com/) is a chat app for AI models. You bring your own API keys from OpenAI, Anthropic, Google, OpenRouter and about 20 other providers, and chat with all of them in one place. It's built by Tony Dinh, who has been building it in public on X since he bought the domain in March 2023.

It makes money two ways. People pay once for a licence ($39, "once + pay per API use", next to "$20/mo" for ChatGPT Plus or Claude Pro on its own pricing page). Companies pay monthly for TypingMind Teams, from $83 a month, to run a chat workspace for their staff.

So TypingMind's buyers are people who pay for AI by the token, or are about to. That makes the searches it should win easy to name: what the API costs, how to get a key, and which model to use.

That gap, 166 visits against 7,287, is the largest in this teardown, and the other three are like it. TypingMind has already built the pages. They're titled, split or hosted in a way that keeps them out of the results.

## The four changes that bring most of the gain

1. Retitle the price pages for the search. "claude api pricing" gets 7,400 US searches a month at a difficulty of 3, and TypingMind has the data.
2. Retitle the API key guides the same way. "anthropic api key" and "claude api key" get 35,000 US searches a month between them, and TypingMind has two pages that answer them.
3. Turn the side-by-side model tests into comparison pages. "claude vs chatgpt" gets 35,000 a month at a difficulty of 8, and TypingMind's X account already runs these tests.
4. Bring back the Teams comparison pages. Their old addresses return a 404, and AI answers about team chat cite LibreChat instead.

Then three technical fixes (a sitemap, links in the homepage HTML and redirects for the old docs) let Google and AI crawlers find all of it.

### 32 pages for one model

The second problem is that each model is listed once per provider that sells it. One page per model, with every provider in a table, is also a better page. Nobody else in the results shows that Bedrock's regional endpoints cost 10% more, or which gateways charge Anthropic's list price.

**The fix:**

1. Title each provider page for the search: "Claude API pricing", "OpenAI API pricing", "Gemini API pricing". Put the price table first in the HTML, with the month in the title.
2. Merge each model's provider pages into one page with a row per provider, and 301 the rest to it. That turns 7,222 model pages into roughly the number of models, each with something the others don't have.
3. Add a "Subscription or API?" section to the Claude and OpenAI pages that uses the calculator. TypingMind already compares "$39 once + pay per API use" with "$20/mo" on its own pricing page. Then give that comparison a page of its own for "is chatgpt plus worth it" (3,700 searches, difficulty 0).
4. Move the tool to www.typingmind.com, where the links are. The main site has about 2,650 referring domains and the Teams site about 800 (Ahrefs).

To confirm it worked, check in Search Console that the Claude page gets impressions for "claude api pricing" within two weeks, and that only one Opus 5.5 address shows up for "claude opus pricing".

## 3. Model comparisons: the side-by-side tests live only on X

Those tests have no web page. The full chats are shared on cloud.typingmind.com/share/, which robots.txt blocks, so Google never sees them. People search for these comparisons in large numbers, at very low difficulty.

## Three technical fixes, closest to revenue first

### 1. The main site has no sitemap

www.typingmind.com has no sitemap, and robots.txt doesn't point to one. That site holds the 2,772 model guides, 72,641 skill pages and 8,207 MCP server pages. Google can only find them through the menu and the directories' numbered pages. The skills directory stops at page 200, which reaches 10,200 of the 72,641 skills, and any later page number shows page 200 again.

  after={{ label: "With a sitemap", html: afterSitemap }}

**The fix:** a sitemap index with the guides, the price pages and the comparison pages first. For skills, list the ones with a reason to rank. The UI UX Pro Max skill page ranks ninth for its name (3,700 US searches), behind GitHub, Reddit and five other sites about the same skill, so 72,641 pages built from GitHub repos won't rank just by being listed. Pages that add what only TypingMind has (which models run the skill, and a button to try it with your own key) will.

To confirm it worked, submit it in Search Console and check the indexed count for the guides a week later.

### 2. The homepage has no links in its HTML

The homepage gets 4,584 of the main site's Google visits, and its HTML links to nothing. The menu and footer appear only after JavaScript runs. Google renders JavaScript, but a crawler or agent that reads the HTML as served gets no links at all. The homepage also has no canonical tag, and /home serves the same page under the same title.

**The fix:** render the menu and footer on the server as plain links, add a self canonical, and 301 /home to the homepage. The pricing pages for both the licence and Teams need a canonical too, because every footer link to the Teams site adds ?ref=typingmind. ## Get the changes seen quickly

Most of these fixes change pages Google already knows under a different title or address. Google won't recrawl 7,000 price pages on your schedule. I'd submit each new and changed URL to [Index My Site](https://indexmysite.app/) the day it ships, so Google is asked to crawl it straight away. That matters most for the merged price pages, where the redirects only count once Google has seen them.

## How I ran this

Everything in this teardown came from SEO Skill, run by an agent. You can run the same audit on your own site.

**1. Connect the hosted MCP server.** It's free. You sign in with Google, and there's no password and nothing to install. In Claude Code:

```sh
claude mcp add --transport http seoskill https://seoskill.dev/mcp
```

Codex, Cursor and Claude on the web work too. The [MCP guide](/docs/mcp) has the steps for each one.

**2. Add a research key.** On your [account page](/account), save an Ahrefs or DataForSEO key. The key gives your agent search volumes, rankings and results pages, like the tables above.

**3. Install the CLI for crawling.** The crawl runs on your machine, so it can read any site:

```sh
npm i -g seo
seo login
```

TypingMind's main site draws its menu with JavaScript, so a plain crawl stops at the homepage. Run `seo crawl` with `--rendering on` for sites like that.

**4. Ask your agent.** This is close to the prompt I used:

```text
Audit example.com and every subdomain we use.
Crawl each one with seo crawl, with rendering on
if the homepage has no links in its HTML.
Count the pages each template makes, and check
their titles against the search each should win.
Use seo_research to find the searches our buyers
make, who ranks for them and whether we can compete.
Ask ai_answers ten buyer questions for us and for
our biggest competitor.
Rank every fix by how close it sits to revenue.
```

On your own site, the hosted server adds the part I couldn't see from the outside: your real Search Console clicks and queries. With those, you get measured numbers where this post has estimates.
